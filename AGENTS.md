# Agent guidance — superconductor/web

1. **Read [`.okf/index.md`](.okf/index.md) first** before changing a controller, a middleware, the sessions or the config. Open only the concepts the change touches.
2. **This is a transport, not the protocol.** Messages, procedures, ids, capabilities and errors belong to superconductor/core; this package moves them over HTTP. A protocol change goes upstream first. See [`.okf/architecture/transport.md`](.okf/architecture/transport.md).
3. **Session logic stays in core's `Mechanism\Session`.** A controller feeds `Session::handle()` and writes what the closure gives it as server-sent events; it never decides what a message means. See [`.okf/architecture/transport.md`](.okf/architecture/transport.md).
4. **One session per `Mcp-Session-Id`, and it runs its own server instance.** `HttpSessions` opens it from the `ServerRepository`, finds it by id and server name, and forgets it on DELETE or when it is idle. A session with an open GET stream or a request in flight is never idle. See [`.okf/server/sessions.md`](.okf/server/sessions.md).
5. **The endpoint is guarded before any controller runs.** `ValidateHost` (Host and Origin against `sse.allowed_hosts`, `*` allows any), then `ValidateProtocolVersion`, then `ResolveSession`, in the order `sse.middleware` lists them. A guard answers with a status and a plain-text reason, never a JSON-RPC error. See [`.okf/architecture/transport.md`](.okf/architecture/transport.md).
6. **Requests are answered on an event stream; notifications and responses get `202`.** A POST that holds requests needs `Accept: text/event-stream` (else `406`, with nothing handled). The stream ends once every request in it is answered or cancelled. See [`.okf/architecture/transport.md`](.okf/architecture/transport.md).
7. **A GET stream never ends a session.** It polls the session's outbox every `sse.session.poll_interval` and ends when the session closes or the client hangs up; a hang-up leaves the session for the client to open another stream. See [`.okf/server/sessions.md`](.okf/server/sessions.md).
8. **Everything swappable is config.** The path, the controller per method, the middleware and the routes file come from `config/sse.php`, and the provider registers them in the container, so an application replaces one through config alone. A key added to `config/sse.php` is described in the README and in [`.okf/reference/config.md`](.okf/reference/config.md); no key is read that the file does not declare.
9. **Refusals are the spec's statuses.** `403` host or origin, `400` protocol version, missing session or batch on a session that does not take them, `404` unknown session or server, `406` missing `Accept`. Reuse them; do not add a status for a case one of them covers.
10. **Tests are Pest v4 and run a real `HttpServer`.** The fixture app in `tests/Fixtures/app` boots Mariner, core and this provider; tests serve it on port 0 and talk to it over raw sockets. A behaviour change comes with a test; `vendor/bin/pest` stays green. `venusian/serve` and `venusian/framework` are in `require-dev`; local checkouts are installed through a gitignored `composer.dev.json`.
11. **Durable facts go in `.okf`.** Update the matching concept, bump its `generated.at`, append `.okf/log.md`. The bundle documents the package, never a session.
12. **Versions** move with superconductor/core's, only past a published tag (now 0.11.0).
